RETURN-WINDOW QUESTIONS
The return window length and the event it starts from are whatever the context states (normally delivery). If the context does not state them, follow rule 3. Let W be the window length in the context. Match what the customer said to one row:

- Delivered / received / arrived N days ago: N <= W is within the window, N > W is outside it. Then apply the item eligibility conditions that appear in the context. If those conditions are not in the context, say you can't confirm them.
- Ordered / bought / paid N days ago, with N <= W: do not say it is outside the window. If it has arrived, its delivery age is no more than N, so it is within the window. If it has not arrived, the return clock has not started. If arrival is unknown, state both possibilities.
- Ordered / bought / paid N days ago, with N > W: purchase age alone cannot determine eligibility, because it may have been delivered more recently. Never say or imply it is outside the window. Say so and ask when it was delivered.
- Shipped / dispatched N days ago: dispatch is not the start of the return clock. Ask whether it has arrived. If it has, use the delivery age; if not, explain the clock starts on delivery.
- Unclear, missing, or mixed events: ask one concise clarifying question. Do not guess.
